# Decision Stats

The tab reads engine-owned lifetime counters from `snapshot.decisionStats`. Both engines use the same collector and reset it when rebuilding the world for a new generation. Pause/resume does not clear it. Snapshots replace the browser's view, so reconnects, late joins, tab changes and replayed history do not add counts. Older servers without this optional field show an unavailable message.

A proposal is not a command. A JEV selection is not controller acceptance. Accepted requests are classified at the commit path as agreement, JEV, or fallback. The three counts sum to their displayed subtotal; percentage shares use that subtotal, and show unavailable for zero. Offline also permits a lone surviving proposal to pass the gate: this is explicitly reported separately as a single-agent acceptance. All-accepted totals include that exception; it must not be called agreement or fallback.

Fallback invocations count calls to backup policy, including HOLD. Accepted/rejected fallback requests use structured controller outcomes; an unnecessary offline request is a retained plan. Invocation and outcome appear as separate history records. Reasons retain their actual codes. Backend `low_confidence` includes absent confidence; `no_valid_proposal` and provider failure codes can cover multiple causes. The UI does not infer finer causes from public rationale text.

Arbitration records are counted once by arbitration ID for request and terminal totals. Pending work is not an error. Confidence bands use the active engine thresholds; null stays unmeasured. Selections with fallback reasons are policy/freshness exclusions; selected proposals rejected at the final gate are counted separately. Latency means use terminal measurements (including timed out/error requests when available); sample counts are shown. Agent inference latency includes terminal intervals with a latency; cancelled/stale intervals are not failures. Reported failures include timeouts where the inference path reports them as failure.

The backend requires matching phase **and duration** for agreement. Medium confidence is deferred, and missing confidence invokes fallback. Offline agreement compares phase only; medium confidence can be accepted if its deterministic policy agrees. Default high/medium thresholds are 0.85/0.6. This feature does not modify thresholds, priorities, providers, or signal rules. Badges identify proposal/JEV mock or live provenance independently; offline measurements are synthetic. Traditional runs report fixed-controller green starts and mark AI sections inapplicable.

Agreement credits both agents once while adding one global decision. JEV selection credit goes to the selected agent; acceptance credit requires controller acceptance. Assigned-direction counters inspect the requested phase, since either agent can request the other direction. Accepted/selected is an acceptance denominator, never a delivery rate.

Realized service requires an accepted same-direction extension or a subsequent green transition carrying its command ID. The collector consumes each pending command only once. Offline transitions now preserve that ID for observation without changing signal scheduling. An extension counts only when it increases the previously committed green end (or minimum-green bound when no end was committed). Immediate realization means an extension was committed, not that the entire requested duration eventually elapsed. Requests still awaiting clearance are pending service, not failures. Only the latest 128 pending correlations are retained; at extreme scale an evicted correlation cannot be credited. Aggregate acceptance totals remain intact. Up to 80 history rows and bounded proposal/arbitration/dedup caches are retained; engine events are emitted in order, while external duplicate/reconnect handling uses authoritative snapshots rather than re-aggregating replayed events. History cycle IDs match Transcript details.

Automatic green starts lacking a command ID are separate from accepted fallback. They do not include initial world construction; fixed-controller counts likewise count emitted green transitions, not the initial green. An accepted extension's later clearance is correlated but does not create another realization. Statistics contain structured public outcomes and no credentials or private reasoning.
